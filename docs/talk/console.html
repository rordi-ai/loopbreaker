One pipeline, six ordered gates, two things an agent cannot fake

Every source edit is refused until an issue clears the gates in order. The premise comes from a human; the proof comes from an exit code. Nothing between the two grades its own work.

⇥ = admission. No worker starts before it. Dashed nodes run on a different vendor (Codex CLI) so review is structurally independent, not promised.

Two hooks make it load-bearing src/hooks.ts

  • SessionStartprime — binds the active issue and states the gate the agent is behind. Unlinked, the plugin is inert.
  • PreToolUseadmission — denies every source edit until shape ✓ planning ✓ independent planning-review ✓, in that order. Bash and reads pass.

The gate isn't advice the agent may follow. It's a wall in front of the editor.

Seven skills, one per role

discovery-interviewshape-strategy plan-featurereview-planning implement-featurereview-invariants orchestrate-delivery

Highlighted two are the reviewers. They inspect and record only — they never edit the shape, contract, or plan they are judging.

Evidence is executed, never asserted

loopbreaker prove BEHAVIOR runs the registered harness and writes the row itself. The verdict is the harness exit code.

  • not_runfail-closed default — failing to observe a pass is never a pass.
  • red-firsta harness must fail against HEAD before the work exists, or it proves nothing.

Two-way harness binding

  • behaviornames its harness — data, cheap, revocable.
  • harnessnames the behavior back in proves — reviewed code, visible in a diff.

Neither half alone counts, so an agent can't quietly point a behavior at a test that cannot fail.

Bounded passes end the loop

Planning review and code review each get comprehensive → repair-verification → decision. There is no pass four.

A round that spends its budget ends the round, not the issue — the open findings become the work list, and re-opening a round is a named human act on the record.

The reviewer is a different vendor

Planning review and code review run on the Codex CLI, injected with the loopbreaker MCP server, recording its own passes and findings.

Independence isn't a second Claude prompt told to be skeptical — it's a different model family that never saw the build.
