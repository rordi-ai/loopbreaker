So: write the commitment down

Architectural invariants

The rules the system must hold. Citable. Versioned. Pre-existing.

− "this seems wrong"
+ "this violates the rule that X"

It works. Findings get shorter, sharper, arguable on the merits.

The trap

Rules multiply findings

Every pass cites another rule. Every repair opens surface for the next pass. The review gets better and stops ending.

Worse than a vibes-spiral: every finding is defensible. Correct, cited, traceable to a rule you wrote and agreed to.

The spiral has your own authority behind it.

My own tool ships with the warning

…situations where repeated fixes risk scope expansion or a failed-review spiral.

— description of the skill I built to give review a basis

The instinct is to loop harder

More passes. More reviewers. Cross-checking.

That adds turns, not information.

If the loop had no terminating condition at pass three, it doesn’t acquire one at pass nine.

What actually ends it

Bounded authority

  • Comprehensive — find the coherent set.
  • Repair verification — check the fixes, only the fixes.
  • Decision — ship, ship with named debt, split, or hold for one named risk.

No pass four. Under any framing.

And: review completion and shipping readiness are different facts. Neither can overwrite the other.

But rules aren’t the whole contract

Invariants say nothing
about this change

What it’s for. What counts as done. What you’re deliberately not building.

If the agent authors that, you’ve reintroduced its priors — with extra steps and a citation format.

A chain of gates checks that each step follows the last.
It cannot check the top.

Rigor does not correct
a bad input.
It certifies it.

So the per-work basis is elicited, not authored

Interview, then ratify

One answer per required field. Recorded verbatim, with the question that produced it — an answer you can’t judge against its question isn’t reviewable.

Then ratified by a human. Which sounds like paperwork.

What I can’t claim

  • The premise has my approval, not a review. Every other layer has an independent one.
  • Red-first is a flag, not a gate. A run shipped claiming it proved its harness red. The substrate disagreed.
  • An agent with a shell can still reach the approval endpoint. Attribution, not prevention.
  • It took six attempts to get an agent through the pipeline at all.

A loop can only check itself
against itself

What ends a review isn’t convergence.
It’s authority, bounded in advance,
over a contract that came from outside the loop.

Half of that contract is standing rules, written once.
The other half has to be asked for, every time.
